# Bulk Serial File Renamer for Linux

Rename a folder of files into clean numbered order without doing each one by hand.


## Download

Download the latest ZIP from the **Releases** section of this GitHub repository.

- Platform: **Linux**
- Current release: **v1.1**

## Who it is for

People with folders full of documents, exports, screenshots, product files, photos, or mixed files that need clean numbered names.

## What it does

- Batch-renames files into numbered order
- Uses a user-chosen base name
- Includes sample files for testing
- Designed for simple desktop use

## Privacy / safety notes

- Use sample files first to test the workflow
- Designed as a local utility

## How to open

1. Download the ZIP from **Releases**.
2. Extract/unzip it.
3. Open the included README or launcher file inside the extracted folder.

Some Linux systems require right-clicking the launcher and choosing **Run as Program**.
