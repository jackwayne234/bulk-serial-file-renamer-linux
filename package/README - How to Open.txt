Bulk Serial File Renamer - Linux v1.1

How to open:
1. Double-click: Launch_Bulk_Serial_File_Renamer
2. If Linux asks, choose Run or Run as Program.

What it does:
- Renames files in sequence using your base name.
- Keeps original file extensions.
- Copy mode ON writes renamed copies into a renamed_files folder.
- Copy mode OFF moves/renames originals into renamed_files.
